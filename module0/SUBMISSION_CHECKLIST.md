# Module 0 Readiness Checklist

Module 0 is required complete/incomplete practice worth 0% of the final course grade. It is not Assignment 1.

## Checkpoint 1 - Environment

- [ ] I used WSL Ubuntu on Windows or Terminal on macOS.
- [ ] Windows only: `wsl --list --verbose` shows the intended Ubuntu distribution and version 2.
- [ ] `g++ --version`, `make --version`, `git --version`, and `code --version` work.
- [ ] Windows only: VS Code shows a WSL-connected window.
- [ ] If setup failed, I saved one exact blocker to share with course staff.

## Checkpoint 2 - Folder and files

- [ ] `pwd` ends in `/csci2350/module0`.
- [ ] `ls -a` shows all seven starter files, including `.gitignore`.
- [ ] Terminal and VS Code Explorer show the same folder.
- [ ] I did not work from Downloads or an unrelated Desktop folder.

## Checkpoints 3-6 - Program and diagnostics

- [ ] I personalized and saved `hello.cpp`.
- [ ] I compiled manually with the full course command.
- [ ] I ran with `./hello` and checked all three lines.
- [ ] I completed the old-executable/recompile experiment.
- [ ] I created, read, and repaired one missing-semicolon error.
- [ ] The final code contains no TODO in the required output lines.

## Checkpoint 7 - Makefile

- [ ] `make clean`, `make`, and `make run` worked.
- [ ] The final `make clean` removed executable `hello` but kept `hello.cpp`.

## Checkpoint 8 - GitHub and LMS submission practice

- [ ] I understand that this is practice, not Assignment 1.
- [ ] `git config --global user.name` prints my intended commit author name.
- [ ] `git config --global user.email` prints my GitHub-associated or GitHub noreply email.
- [ ] I created a meaningful local commit.
- [ ] I published or synced the commit.
- [ ] I opened the repository in a browser.
- [ ] All seven starter files are visible.
- [ ] The executable `hello` is not visible.
- [ ] I followed the repository-visibility rule shown in the LMS.
