# Start Here - Module 0

1. Open the Module 0 study guide and follow the route for your operating system.
2. Download `CSCI2350_Meeting01_Classroom_Code.zip` from the LMS.
3. Extract it. The extracted folder must be named `module0`.
4. Put the entire folder at `~/csci2350/module0`.
5. Run `pwd` and `ls -a`; confirm the path and all seven starter files.
6. Open the same folder in the correct VS Code context with `code .`.
7. Follow `MODULE0_READINESS_CHECK.md` checkpoint by checkpoint.
8. If a step fails, stop repeating it and use `TROUBLESHOOTING.md` to save one exact blocker.
9. Finish with `SUBMISSION_CHECKLIST.md`.

The GitHub/LMS step is submission-workflow practice, not Assignment 1. Assignment 1 releases at the end of Module 2 and uses the same publish, verify, and submit pattern.
