# CSCI 2350 — Meeting 03 classroom code

Every slide activity uses the same command pattern: `make 1`, `make 2`, and so on.
You do **not** need to read or edit the Makefile.

## Classroom routine

1. Open only the file named on the slide.
2. Read the short header at the top of that file.
3. Predict before running.
4. Edit only the line or region marked `TODO`.
5. Run the matching numbered command.
6. Compare the output with your prediction.
